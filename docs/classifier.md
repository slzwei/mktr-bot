# Callee response classification

`MKTR_CLASSIFIER_MODE` selects `rules` (the default) or `openai`. Selecting OpenAI requires `OPENAI_API_KEY`; a missing key produces a startup error instead of silently changing the selected mode. The model remains configurable through `MKTR_OPENAI_CLASSIFIER_MODEL`, retaining the existing `gpt-4o-mini` default.

The OpenAI implementation sends one structured Responses request with `AbortSignal.timeout(MKTR_CLASSIFIER_TIMEOUT_MS)`, where the default is 1500 ms. Per-request SDK retries are disabled, so retries cannot extend the silence heard by the callee. The wrapper also races the abort signal against the provider result, bounding a faulty provider that ignores cancellation. Timeouts, provider errors, and invalid output each return the deterministic rules result and increment `mktr_classifier_fallbacks_total` with a bounded reason label. One classification latency observation includes the attempted request and any fallback. The fallback log records only the reason and provider; it omits transcripts and raw error bodies. Requests set `store: false`.

Rules normalize case, whitespace and apostrophes. Explicit contact refusals and product refusals are considered first, so “don't call me back” and a refusal containing “interested” cannot become a positive or callback match. A request to call later can follow a bare “no”, so “no, call me later” is a callback. Temporary unavailability (“not free”, “busy now”, “later”) also maps to callback. Standalone Singapore English acceptance (“can”, “can lah”, “ok can”) maps to interested; uncertain replies and requests to repeat remain unknown.

`server/fixtures/classifier-transcripts.json` contains 89 distinct regression cases, including the audit examples. `npm run test:classifier` requires every case to match, exercises malformed/provider errors, and uses the actual installed OpenAI SDK against a hanging loopback HTTP server to verify one aborted request and a rules result within two seconds. These are fake-provider checks; they do not establish the accuracy or latency of any live provider.

The implementation follows the [official Responses API reference](https://developers.openai.com/api/reference/typescript/resources/responses/methods/create). The installed SDK's `responses.parse(body, options)` implementation and `RequestOptions` declarations were inspected for `signal`, `timeout`, and `maxRetries` before implementation; the loopback test verifies those options without an external API request.
